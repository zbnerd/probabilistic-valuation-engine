## 핵심 패턴

1. **Poison message / 무한 redelivery** (#2, #4) — DLQ나 `DefaultErrorHandler` 설정 없음
2. **ACK-before-complete** (#3, #15) — 비동기 작업 완료 전 ACK → crash 시 데이터 유실
3. **Semaphore early release** (#5, #6) — handler 완료 전 permit 반환 → 동시성 제한 무력화
4. **Virtual thread executor shutdown 누락** (#8, #21) — graceful shutdown 없음
5. **Airflow 409 처리** (#9, #10) — CONFLICT를 실패로 처리 → 전체 DAG 중단
6. **비원자적 Redis 쓰기** (#11, #14) — delete-then-write, batch 중간 trim
